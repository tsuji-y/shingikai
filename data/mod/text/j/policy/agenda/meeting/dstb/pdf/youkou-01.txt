防 衛 科 学 技 術 委 員 会 設 置 要 綱

（ 設 置 ）

第 １ 防 衛 省 が 直 面 す る 科 学 技 術 及 び 安 全 保 障 に 係 る 諸 課 題 の 解 決 に 向 け た
科 学 技 術 に 関 す る 政 策 及 び 施 策 の 企 画 立 案 の 促 進 に 資 す る た め 、 防 衛 省 に
防 衛 科 学 技 術 委 員 会 （ 以 下 「 委 員 会 」 と い う 。） を 設 置 す る 。

（ 討 議 事 項 等 ）

第 ２ 委 員 会 は 、 科 学 技 術 及 び 安 全 保 障 に 係 る 重 要 な 事 項 に つ い て 討 議 を 行

い 、 防 衛 大 臣 に 対 し 必 要 な 助 言 又 は 提 言 を 行 う 。

（ 構 成 等 ）

第 ３ 委 員 会 は 、 委 員 長 （ 防 衛 大 臣 科 学 技 術 顧 問 ）、 委 員 長 代 理 及 び 委 員 を

も っ て 構 成 す る 。

２ 委 員 会 の 委 員 は 、 科 学 技 術 に つ い て 様 々 な 専 門 知 識 を 有 す る 学 識 経 験 者

及 び 実 務 経 験 者 の う ち か ら 、 そ れ ぞ れ 防 衛 大 臣 が 委 嘱 す る 。

３ 委 員 長 は 、 防 衛 大 臣 が 指 名 す る 委 員 を も っ て 充 て る 。
４ 委 員 長 は 、 委 員 会 を 招 集 し 、 会 務 を 総 理 す る 。
５ 委 員 長 代 理 は 、 委 員 長 が 指 名 す る 委 員 を も っ て 充 て る 。
６ 委 員 長 代 理 は 、 委 員 長 を 助 け 、 委 員 長 が 不 在 の 場 合 、 そ の 職 務 を 代 理 す

る 。

７ 委 員 は 、 原 則 と し て 防 衛 省 参 与 を も っ て 充 て る 。
８ 委 員 の 任 期 は 、 原 則 と し て ２ 年 と し 、 再 任 を 妨 げ な い 。
９ 委 員 長 は 、 委 員 会 に お け る 討 議 の た め 必 要 が あ る と 認 め る と き は 、 第 １
項 に 掲 げ る 委 員 以 外 の 者 を 委 員 会 に 参 加 さ せ 、 意 見 を 述 べ さ せ る こ と が で
き る 。

（ タ ス ク フ ォ ー ス ）

第 ４ 委 員 長 は 、 委 員 会 が 行 う 助 言 又 は 提 言 に 必 要 な 検 討 及 び 作 業 を 行 う た

め 、 委 員 会 の 下 に 、 複 数 の タ ス ク フ ォ ー ス を 置 く こ と が で き る 。

２ タ ス ク フ ォ ー ス の 議 長 は 、 委 員 長 が 指 名 す る 委 員 を も っ て 充 て る 。
３ 議 長 は 、 タ ス ク フ ォ ー ス の 会 議 を 招 集 し 、 タ ス ク フ ォ ー ス の 事 務 を 総 括

す る 。

４ タ ス ク フ ォ ー ス の 構 成 員 は 、 議 長 が 指 名 す る 。
５ 議 長 は 、タ ス ク フ ォ ー ス に お け る 討 議 の た め 必 要 が あ る と 認 め る と き は 、
前 項 に 規 定 す る 構 成 員 以 外 の 者 を タ ス ク フ ォ ー ス に 参 加 さ せ 、 意 見 を 述 べ
さ せ る こ と が で き る 。

（ 事 務 局 ）

第 ５ 委 員 会 及 び タ ス ク フ ォ ー ス を 支 援 し 、 討 議 並 び に 検 討 及 び 作 業 に 必 要

な 事 務 を 行 う た め 、 委 員 会 の 下 に 事 務 局 を 置 く 。

２ 事 務 局 の 構 成 は 、 次 の と お り と す る 。

⑴ 事 務 局 長 防 衛 装 備 庁 技 術 戦 略 部 長
⑵ 事 務 局 長 代 理 防 衛 装 備 庁 技 術 戦 略 部 革 新 技 術 戦 略 官
⑶ 事 務 局 員 防 衛 装 備 庁 技 術 戦 略 部 技 術 戦 略 課 長

防 衛 装 備 庁 長 官 が 指 定 す る 科 学 技 術 戦 略 官
防 衛 装 備 庁 長 官 が 指 定 す る 科 学 技 術 戦 略 官 補 佐
そ の 他 事 務 局 長 が 指 定 す る 者

（ 関 係 部 局 の 協 力 ）

第 ６ 委 員 長 は 、 委 員 会 に お け る 討 議 の た め に 必 要 が あ る と 認 め る と き は 、
関 係 部 局 に 対 し 、 関 係 者 の 出 席 、 資 料 の 提 供 そ の 他 の 協 力 を 求 め る こ と が
で き る 。

２ 議 長 は 、 タ ス ク フ ォ ー ス に お け る 活 動 の た め に 必 要 が あ る と 認 め る と き
は 、 関 係 部 局 に 対 し 、 関 係 者 の 出 席 、 資 料 の 提 供 そ の 他 の 協 力 を 求 め る こ
と が で き る 。

３ 関 係 部 局 は 、 前 項 の 求 め が あ っ た 場 合 に は 、 こ れ に 応 じ 、 協 力 す る も の

と す る 。

（ 秘 密 を 守 る 義 務 ）

第 ７ 委 員 及 び 構 成 員 は 、 職 務 上 知 る こ と の で き た 秘 密 を 漏 ら し て は な ら な

い 。 そ の 職 を 退 い た 後 も 同 様 と す る 。

（ 委 任 規 定 ）

第 ８ こ の 要 綱 に 定 め る も の の ほ か 、 委 員 会 の 議 事 の 手 続 そ の 他 必 要 な 事 項
は 委 員 長 が 、 タ ス ク フ ォ ー ス の 議 事 の 手 続 そ の 他 必 要 な 事 項 は 議 長 が 、 こ
の 要 綱 の 実 施 に 関 し 必 要 と な る 細 部 事 項 は 防 衛 装 備 庁 長 官 が 、 そ れ ぞ れ 定
め る 。
